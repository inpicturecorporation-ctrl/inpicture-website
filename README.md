# Inpicture website

Static website for ioniantool.pro. Upload the contents of this directory to the root of a GitHub repository (not inside another folder).

1. In repository Settings > Pages, choose Deploy from a branch, main, / (root), Save.
2. Set the custom domain to ioniantool.pro. CNAME already contains it.
3. Configure Hostinger DNS following GitHub Pages documentation. Keep email MX/TXT records unchanged.
4. Enable Enforce HTTPS once GitHub provisions its certificate.

Before making the repository public, review its contact email, artwork and privacy text. It includes public website files only; no app source, passwords or signing keys.
